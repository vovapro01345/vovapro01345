## 🛠️ Мои проекты

### [Real_Speak](https://realspeak.ddns.net/) — мессенджер
> Децентрализованный PWA-мессенджер с поддержкой Web Push, кастомными звуками и двусторонней аутентификацией.

### [Real_Studio](https://github.com/vovapro01345/Real_Studio)
> Мой личный сайт на HTML.

### [rbs_compiler](https://github.com/vovapro01345/rbs_compiler)
> Многопоточный компилятор формата RBS (Real Bit Stream) для приставочной ОС Real_X.  
> Использует LZ4-сжатие и rolling XOR-шифрование. Поддерживает drag-and-drop папок для сборки игр.
