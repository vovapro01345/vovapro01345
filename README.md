## 🛠️ Мои проекты

### [Real_Speak](https://realspeak.ddns.net/) — мессенджер
> Децентрализованный PWA-мессенджер с поддержкой Web Push, кастомными звуками и двусторонней аутентификацией (TOTP).  
> Устанавливается как приложение, поддерживает ботов и токены.

### [Real_Studio](https://github.com/vovapro01345/Real_Studio)
> Мой личный сайт на HTML.

### [rbs_compiler](https://github.com/vovapro01345/rbs_compiler)
> Многопоточный компилятор формата RBS (Real Bit Stream) для приставочной ОС Real_X.  
> Использует LZ4-сжатие и rolling XOR-шифрование. Поддерживает drag-and-drop папок для сборки игр.

### [source_loader_to_rust](https://github.com/vovapro01345/source_loader_to_rust)
> Загрузчик исходников на Rust.

### [decay-launcher](https://github.com/vovapro01345/decay-launcher)
> Лаунчер для игрового проекта Decay.

### [decay-game](https://github.com/vovapro01345/decay-game)
> Игровой проект Decay.
